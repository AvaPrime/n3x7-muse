# N3X7 / MUSE Music Intelligence Workbench

> **Not a music generator. A system for music understanding, taste, inspiration, curation, and sonic engineering.**

N3X7 is the first artist implementation and proving ground. MUSE is the music-domain intelligence layer. Provider integrations such as Suno, Udio, Lyria, DAWs, DJ platforms, distributors, and social platforms are adapters — not sources of truth.

## Status

**Classification:** M0 — Executable Foundation / Provisional Domain

This repository is an executable UI scaffold with local mock data and architecture documentation.

**Implemented (OBSERVED):** information architecture, responsive visual shell, minimal Sonic Map concept, track/taste/prompt domain vocabulary, navigation, documentation contracts (ADRs + invariants), ProviderAdapter boundary, EpistemicStatus model.

**Not implemented:** authentication, persistence, audio DSP, ML inference, provider APIs, distribution, payments, biometric inputs, autonomous publishing, or high-fidelity visual systems.

**Important:** The high-fidelity N3X7 Artist OS dashboard mockup is the visual north star only. It is not an implementation claim. Domain vocabulary remains provisional pending ADR-0004.

## North star

Human intent → structured understanding → exploration → synthesis → verification → curation → feedback.

The human remains the artist. MUSE expands creative possibility without surrendering identity, memory, or sovereignty to vendors.
