# Domain Model

Core entities:

- ArtistProfile
- Track
- TrackGeneration
- TrackLineage
- CreativeEpisode
- CreativeGenome
- TasteModel
- ReferenceArtifact
- PromptArtifact
- AlbumGenome
- Release
- ReleasePackage
- ProvenanceRecord
- MixabilityVector
- QualityAssessment
- ProviderAdapter
- AudienceSignal

Relationships are first-class. A track may derive from multiple generations, references, creative episodes, and prompt artifacts.
