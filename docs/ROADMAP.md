# Roadmap

## M0 — Foundation
Identity, domain contracts, UI shell, documentation.

## M1 — Ingestion
Import 1,000+ existing tracks; canonical IDs; hashes; version grouping; provenance capture.

## M2 — Music Intelligence
BPM, key, beat grid, energy, loudness, spectral/timbre features, structure, stems, semantic analysis.

## M3 — Creative Genome
Unified representation of sonic, semantic, structural and contextual attributes.

## M4 — Intelligent Library
Search, clustering, similarity, taste, mixability, lineage, album candidates.

## M5 — Creative Loop
Intent/CIR → provider adapter → analysis → quality gate → human selection → learning.

## M6 — Release OS
Artwork, metadata, provenance, release packages, distribution adapters.

## M7 — AV / Live
Music-temporal events → visuals, lighting, spatial audio, live performance.

## M8 — Productization
Artist OS, API, venue, education, label and enterprise products.
