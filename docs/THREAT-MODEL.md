# Threat Model v0.1

Primary risks:

- Provider lock-in.
- Terms-of-service violations through scraping or reverse engineering.
- Rights ambiguity.
- Accidental style imitation.
- Loss of provenance.
- Unreviewed autonomous publication.
- Data leakage from private creative libraries.
- Vendor model changes causing silent behavioural drift.
- AI-generated spam/slop overwhelming curation.
- Biometric or audience data misuse in future live systems.

Mitigations begin with provider-neutral adapters, provenance-first records, human release gates, explicit consent, local/canonical ownership, and observed/inferred/proposed separation.
